# AI Assistant Feature Recommendations (100% Free)

This document maps out how you can upgrade your MERN AI assistant to perform key features found in premium platforms like **ChatGPT Plus**, **Gemini Advanced**, and **Claude 3.5 Sonnet** using **only free APIs and native SDK tools**.

---

## 1. Live Google Search Grounding (Web Browsing) - [COMPLETED (BACKEND)]
* **Goal:** Allow the assistant to search the internet for real-time facts, news, and queries.
* **Cost:** $0 (Free built-in tool in the Gemini API).
* **How it works:** 
  You can enable Google Search grounding directly via the Google Gen AI SDK. When enabled, Gemini performs a search, uses the findings to answer, and returns web citations.
* **Backend Implementation:**
  Modify the `generateAIResponse` call in [ai.service.js](file:///d:/MERN-PROJECT/Full%20Stack%20AI%20-%20Assistant/backend/src/services/ai.service.js) to include search tools:
  ```javascript
  const response = await ai.models.generateContent({
    model: config.GEMINI_MODEL,
    contents: chatHistory,
    config: {
      // Enables live Google Search grounding
      tools: [{ googleSearch: {} }]
    }
  });
  ```

## 2. Sandboxed Code Execution (Advanced Data Analysis)
* **Goal:** Let the assistant write and execute Python code dynamically to solve complex math, analyze data, or generate outputs.
* **Cost:** $0 (Free built-in tool in the Gemini API).
* **How it works:** 
  Gemini will run its own generated Python code inside an isolated sandbox and feed the output back into the conversation.
* **Backend Implementation:**
  Add the code execution tool configuration in [ai.service.js](file:///d:/MERN-PROJECT/Full%20Stack%20AI%20-%20Assistant/backend/src/services/ai.service.js):
  ```javascript
  const response = await ai.models.generateContent({
    model: config.GEMINI_MODEL,
    contents: chatHistory,
    config: {
      tools: [{ codeExecution: {} }]
    }
  });
  ```

## 3. Multimodal Support (Image & Document Upload)
* **Goal:** Enable users to upload images, PDFs, CSVs, or text files for the assistant to analyze.
* **Cost:** $0.
* **How it works:**
  * **Images:** Gemini's API supports image inputs natively. Send the image as a base64 string from the frontend to the backend socket, and include it in the `contents` payload:
    ```javascript
    // Inside the messages part array:
    {
      inlineData: {
        mimeType: "image/jpeg",
        data: "BASE64_IMAGE_STRING_HERE"
      }
    }
    ```
  * **PDFs & Documents:** Since Gemini has a **1 million token context window** (Gemini 2.5 Flash), you do not need complex vector databases (RAG) for simple file chats. Install `pdf-parse` (for PDFs) or `mammoth` (for DOCX) in the backend. Extract the text from uploaded files and prepend it to the chat history:
    ```javascript
    // Example context prepending
    const documentText = "Document Content: ..."; 
    // Append to the system prompt or the user's message
    ```

## 4. Claude-style Interactive "Artifacts"
* **Goal:** When the AI writes HTML, CSS, SVG, JavaScript, or React code, display it in a beautiful visual preview panel in the frontend.
* **Cost:** $0 (Pure frontend implementation).
* **How it works:**
  1. Detect code blocks in the frontend using regex or markdown parser (e.g. ```` ```html ```` or ```` ```xml ```` for SVG).
  2. Separate the code block from the standard chat stream.
  3. Render it inside a side-by-side split pane:
     - For **HTML/CSS/JS**: Render inside a sandboxed `<iframe>` using the `srcDoc` attribute.
     - For **SVGs**: Render the raw SVG code inside a React component.
     - For **Mermaid Diagrams**: Use the `mermaid` package to draw flowcharts.

## 5. Voice Input & Output (Voice Chat)
* **Goal:** Talk to the assistant and have it talk back.
* **Cost:** $0 (Built-in Web Browser APIs).
* **How it works:**
  * **Speech-to-Text (STT):** Use the web browser's native **Web Speech API** (`window.SpeechRecognition` or `window.webkitSpeechRecognition`). It translates user speech to text locally on the client without sending it to external paid APIs.
  * **Text-to-Speech (TTS):** Use `window.speechSynthesis` on the frontend to read out the text responses generated by the model.

## 7. Custom Personas & System Prompts (Custom GPTs / Projects)
* **Goal:** Allow users to create custom assistant personalities (e.g., "React Coding Coach", "Language Tutor").

## 8. Function/Tool Calling (Agent Actions)
* **Goal:** Let the assistant execute real JavaScript/Node functions (e.g., fetch real-time weather, query database, calculate math) when the user asks a relevant question.
* **Cost:** $0.
* **How it works:**
  Define function declarations in the Gemini API configuration. If Gemini determines it needs to call a function, it halts generation and sends a request back to your backend. Your backend executes the local JS function, sends the output back to Gemini, and Gemini finishes writing the response.
  ```javascript
  // Native SDK tool definition
  config: {
    tools: [{
      functionDeclarations: [{
        name: "getWeather",
        description: "Get current weather for a location",
        parameters: { type: "OBJECT", properties: { location: { type: "STRING" } } }
      }]
    }]
  }
  ```

## 9. Structured JSON Outputs (Quiz/Card Generators)
* **Goal:** Force the model to output strict JSON schemas (e.g. to build interactive flashcards, quizzes, or flowchart nodes in the UI).
* **Cost:** $0.
* **How it works:**
  Specify `responseMimeType: "application/json"` and define a schema in the SDK. Gemini will guarantee the output is valid JSON matching your schema.
  ```javascript
  config: {
    responseMimeType: "application/json",
    responseSchema: {
      type: "OBJECT",
      properties: {
        questions: {
          type: "ARRAY",
          items: { type: "STRING" }
        }
      }
    }
  }
  ```

## 10. URL Link Scraping (Summarize Web Pages)
* **Goal:** Let users paste any website URL and ask the assistant to summarize or talk about it.
* **Cost:** $0.
* **How it works:**
  Use simple backend packages like `axios` and `cheerio` to fetch the raw HTML, extract the main text from tags (`<p>`, `<h1>`, etc.), clean it, and insert it into the user message context before sending it to Gemini.

## 11. Real-time Audio Streaming (Gemini Live API)
* **Goal:** Direct speech-to-speech interaction (low-latency talking conversation, similar to Gemini Live / GPT Advanced Voice).
* **Cost:** $0 (Free-tier Websocket support in Gemini 2.0/2.5).
* **How it works:**
  Establish a WebSocket connection directly from the browser/backend to the Gemini Multimodal Live API (`ws://generativelanguage.googleapis.com/...`). Stream raw microphone audio packets directly to the model and play back the audio stream received.
